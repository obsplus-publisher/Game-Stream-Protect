游戏直播里最难受的时刻，往往不是操作失误，而是画面上多出来一块不该给观众看的东西——一条私信、一个后台页面、一行游戏里的系统提示。

这类事故不是手慢，是直播画面本身没有一层保护。游戏直播保护助手就是这层保护。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **画面保护** | 给 OBS 画面叠加保护效果，把不想出镜的部分挡住 |
| **只挡输出的那一路** | 保护作用在推流画面上，你本机要看的聊天、后台、数据照常看 |
| **范围自己框** | 保护区域的位置、大小按你的画面来定，换布局重新框一下就行 |
| **随时开关** | 需要时打开、不需要时关掉，不用删掉重建，也不影响正常画面 |
| **插件形态** | 装在 OBS 里运行，原有场景、来源、推流设置都不用改 |

## 三步上手

**1. 打开 OBS 插件中心**

在 OBS 右下角的控制按钮面板里点【插件中心】。

还没装插件中心的话，先下载 [OBS 直播管家](https://www.obsworks.com/gj/)，管家会自动为你的电脑把插件中心装好。

**2. 搜索并一键安装**

打开插件中心，登录账号，在最上方的搜索栏里搜「游戏直播保护助手」，也可以在插件列表里按分类翻到它。进入详情页点【一键安装】，稍等片刻即可完成。

**3. 添加保护效果**

安装完成后回到 OBS，就能给画面添加保护效果了。建议开播前先预览一次，确认遮挡范围符合预期再正式开播。

> 全程不用手动替换 OBS 目录里的文件，也不用重启电脑，装好之后插件就在 OBS 里待命。

## 直播里哪些地方需要保护

| 场景 | 容易露出去的内容 |
| --- | --- |
| **端游直播** | 游戏内聊天窗、好友申请、系统提示、账号与角色信息 |
| **手游 / 模拟器直播** | 模拟器侧边栏、手机通知、投屏时的隐私弹窗 |
| **多屏主播** | 副屏上的聊天软件、后台网页、素材与脚本 |
| **切窗口的那几秒** | 从游戏切到桌面、切到浏览器时的"空窗期" |
| **和观众互动时** | 打开后台看数据、看私信、看收益的瞬间 |
| **开播前准备** | 调试 OBS、整理素材、登录账号的过程 |

共同点是：这些内容对直播没有帮助，露出来只会带来麻烦。

## 常见问题

<details>
<summary><b>装了插件，OBS 原来的场景和设置会变吗？</b></summary>

不会。插件是以插件形式装进 OBS 的，原有场景、来源、滤镜和推流设置都保留，只是多了一个可以添加的保护效果。
</details>

<details>
<summary><b>OBS 右下角找不到【插件中心】按钮怎么办？</b></summary>

说明还没装插件中心。下载 [OBS 直播管家](https://www.obsworks.com/gj/) 装一遍，管家会自动把插件中心装到电脑上，之后 OBS 里就有入口了。
</details>

<details>
<summary><b>插件中心里搜不到这个插件？</b></summary>

先在插件中心登录账号，再在顶部搜索栏搜「游戏直播保护助手」；也可以直接在插件列表里按分类翻找。列表持续更新，版本较旧时刷新一下插件中心。
</details>

<details>
<summary><b>支持哪些 OBS 版本？</b></summary>

支持 OBS 27、29、30、31、32 及更高版本。用的是很旧的 OBS 的话，建议先在插件中心或管家升级到较新版本再装。
</details>

<details>
<summary><b>加了保护，自己还能看到被挡住的内容吗？</b></summary>

能。保护作用在推出去的那一路画面上，你在本机该看的聊天、后台、数据照常看，不影响自己判断和操作。
</details>

<details>
<summary><b>开播前怎么确认保护效果没问题？</b></summary>

开播前先做一次预览：在 OBS 里把保护效果加上，用预览窗口或录一小段确认遮挡范围；正式开播后再扫一眼直播间画面。养成这个习惯，基本不会翻车。
</details>

<details>
<summary><b>直播内容合规要注意什么？</b></summary>

插件只负责遮挡画面，直播内容本身仍需遵守各平台规范与法律法规。各平台对直播画面的要求不同，涉及细节请先咨询平台客服确认。
</details>
